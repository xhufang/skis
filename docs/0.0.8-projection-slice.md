# 标量与可复用用户投影

> 本文按 `0.2.8-SNAPSHOT` 维护；文件名保留历史链接。当前公开版本为 `0.2.0`，本分支能力累计到 `0.3.0`。

## 标量结果

```java
PetTable pet = PetTable.petTable;
List<String> names = executor.select(pet.name()).from(pet).where(pet.id().eq(7L)).fetchList();
```

`NonNullSelectable<V>` 与 `Selectable<V>` 表达声明的值可空性，最终外连接可空性仍由当前查询块验证。
SELECT 单行结果统一为 `SingleRow<R>`，因此可空标量的 SQL NULL 行不会丢失为无行。集合、分页及资源流保留
合法 null。单列子查询仍保留独立的形状和 Java 类型检查。

## 在调用点绑定结果形状

SKIS 不生成或增强 DTO。用户声明 record 或普通类：

```java
@ReusableProjection
public record PetSummary(Long id, String name, BigDecimal weight) {}
```

APT 在声明类型的 `.skis` 子包生成 `PetSummaryPro`。按构造器参数顺序绑定类型兼容的表达式：

```java
ProjectionSelection<PetSummary> summary = PetSummaryPro.of(pet.id(), pet.name(), pet.weight());
PetSummary result = executor.select(summary)
    .from(pet)
    .where(pet.id().eq(7L))
    .fetchOne()
    .orElseThrow();
```

来源可以是当前查询块的实体、Join 或受支持表达式，不把结果类型绑定到单一实体泛型。
record 使用规范构造器；普通类须有一个可明确选择的 public 构造器，存在歧义时使用 `@ProjectionConstructor`。
APT 验证参数数量、Java 类型、可空性及生成子包的可访问性，错误通过稳定 APT 编码定位。

Pro 通过 query.spi 生成合同提供直接 Decoder 工厂，不依赖投影发现索引、DTO 字节码增强或逐行反射。
最终选择顺序驱动按 ResultSet 列下标的解码；参数值与结果形状分离，等形查询可复用有界共享计划。

## 另一种声明方式

提前确定属性来源的业务结果使用 `@SpecialProjection`、`@PropertyFrom` 和 `XxxPro.all()`，详见
[专用投影与属性来源](0.0.9-projection-refactor.md)。两种方式共用结果编译、作用域校验和生成式解码。

当前支持 Join、排序、分页、子查询与派生来源；用户聚合 DSL 及 GROUP BY/HAVING 归 `0.2.9`。
Tuple/Map/Row 等未来结果形式不因出现在架构目标中而成为当前支持合同。
