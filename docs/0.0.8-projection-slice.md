# SKIS 0.0.8 标量与生成式投影闭环

0.0.8 在既有单表查询执行链路上加入标量投影和用户类型投影。用户继续通过线程安全的
`SkisExecutor` 或事务内 `SkisSession` 查询；选择列、谓词、方言渲染、JDBC 执行和资源释放仍进入同一套
SQL AST 与执行内核。

## 标量投影

非空列可以直接作为选择结果，来源实体类型会保留到 `from` 阶段：

```java
PetTable pet = PetTable.PET;

List<String> names = executor.select(pet.name())
    .from(pet)
    .where(pet.id().eq(7L))
    .fetch();
```

`select(QueryColumn<E, V>)` 返回 `SelectFromStep<E, V>`，因此不能把 `Pet` 的列与其他实体的表错误组合。
当前 `fetchOne()` 使用 `Optional` 表达“没有行”，为避免把 SQL `NULL` 与“没有行”混为一谈，可空列不能直接
作为标量结果；应使用下面的用户投影把一行包装成非空结果对象。

## 用户 record 或类投影

SKIS 不生成 DTO。用户声明自己的 record 或普通类，并添加 `@SkisProjection`：

```java
@SkisProjection
public record PetSummary(Long id, String name, BigDecimal weight) {}
```

APT 在 `io.example.skis` 子包生成 `PetSummaryProjection`。调用方按构造器参数顺序传入类型兼容的列：

```java
Projection<Pet, PetSummary> summary = PetSummaryProjection.of(
    pet.id(),
    pet.name(),
    pet.weight()
);

PetSummary result = executor.select(summary)
    .from(pet)
    .where(pet.id().eq(7L))
    .fetchOne()
    .orElseThrow();
```

record 使用规范构造器。普通类必须只有一个 `public` 构造器，或用 `@ProjectionConstructor` 标记一个
`public` 构造器。所选构造器必须至少有一个参数，不得是可变参数、泛型构造器，也不得声明 `throws` 子句。
参数类型及其嵌套声明、泛型参数和类型使用注解必须能从生成的 `.skis` 子包访问；由其他 APT 生成的参数类型会跨轮等待，
处理结束时仍不可用则报告稳定错误码。基本类型参数不能绑定可空列；引用类型参数可以接收 Codec 返回的 `null`。

生成映射器只创建 `Projection` 和 `RowDecoder`，不修改用户类型、不扫描运行时注解，也不使用反射。
每个值由实体生成式 `JdbcTypeCodec` 按一基 ResultSet 下标读取，只选择调用方实际提供的列。

## 计划复用

无别名单表投影使用 `QueryPlanCatalog` 共享的有界 LRU，默认最大 4096 项并在 30 分钟未访问后过期。缓存键包含：

- 规范实体元数据身份；
- APT 生成映射器持有的强类型静态令牌身份；
- 选择属性的顺序和重复形状；
- 无条件或等值谓词属性序号。

普通参数值不进入缓存键。同一投影结构使用不同 ID 或名称查询时复用同一个 `CompiledQueryPlan`，执行时只替换
独立参数对象。令牌的结果泛型阻止不同结果 Decoder 因调用方选择相同类键而发生类型混用。显式别名由用户输入，暂不
进入共享缓存；同一个不可变查询对象仍使用私有原子槽复用其计划。

非 Spring 装配可以通过 `SkisExecutorFactory.Builder` 配置最大容量和访问过期时间。`SkisExecutor` 暴露不可变的
hit、miss、eviction、invalidation 和容量统计快照以及显式清空操作；底层 `QueryPlanCatalog` 还支持按规范实体
元数据身份定向失效。

## 数据库、安全与资源合同

- H2 集成测试覆盖标量、用户 record 和事务 Session 查询。
- PostgreSQL CI 服务覆盖真实 PostgreSQL 驱动下的标量和用户 record 投影。
- 恶意字符串只能作为 PreparedStatement 参数绑定，不进入 SQL 模板或 AST。
- ResultSet、PreparedStatement 和普通执行器获取的 Connection 在成功和失败路径均沿用 JDBC 内核的确定关闭语义。

## 当前限制

- 只支持单表投影以及零个或一个等值谓词。
- 暂不支持 Join、聚合、表达式投影、排序、分页、Tuple、Map、Row 或投影工厂方法。
- 可空标量必须包装到非空用户投影结果中。
- 用户投影类型和所选构造器不得声明类型参数；普通类工厂方法支持留给后续切片。
- 显式别名投影不进入共享计划缓存。
