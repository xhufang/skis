# JDBC、元模型与方言编译基础

> 本文按 `0.2.7-SNAPSHOT` 维护；文件名保留历史链接。当前公开版本为 `0.2.0`，本分支能力累计到 `0.3.0`。

## 连接与资源所有权

`io.skis.jdbc.spi.ConnectionProvider` 是执行内核的连接获取与归还入口。
`DataSourceConnectionProvider` 从 DataSource 获取连接，release 时关闭或归还连接池；事务所有权由明确的
Provider/Session 决定。Spring 应用使用独立的 `SpringConnectionProvider` 加入已有 Spring 事务。

成功获取连接后，执行器在所有成功和失败路径归还自己拥有的连接。资源释放顺序为 ResultSet、Statement、
connection release；清理失败保留主异常及 suppressed，不能覆盖原始执行失败。

## 元模型、AST 与调用值

APT 生成规范的实体/属性元数据、表、Binder 和按列下标读取的 Decoder。业务代码使用生成表及 `Sql` DSL，
不直接引用完整分析器或 JDBC 执行实现。方言 SPI 使用 `skis-sql-ast` 的同一套不可变结构模型。

逻辑参数槽保存序号、Java/SQL 类型及 nullability，普通调用值独立保存并按最终 SQL 的槽位绑定。
参数值不进入 AST、结构哈希、缓存键或 SQL 文本。重复逻辑参数的每次物理出现均按最终布局绑定。

## 编译、lowering 与渲染

`skis-dialect-support` 的 `SqlCompiler` 提供无数据库安全编译入口。流程为受控解析、递归方言能力及自定义
校验、方言 lowering、可移植规范化、后校验、最终参数布局和 SQL 渲染。Renderer 只消费目标绑定的
`RenderInput`；阶段对象不能由外部拼装 analysis 或 trusted 标志绕过。

完整接口、第三方方言依赖和身份约束见[方言 SPI 与受控编译](dialect-compilation.md)。分页 count 内部结构已实现；
用户聚合 DSL、GROUP BY/HAVING 和聚合类型规则继续归 `0.2.9`。

## 标识符与 Codec

PG/H2 对 catalog、schema、表、列和别名分别验证、引用，保留声明大小写。DDL 与元数据须使用相同的标识符
拼写；H2 未引用名称的大小写折叠不能替代精确引用规则。不支持的 catalog 限定在渲染前拒绝。

PostgreSQL JSON Codec 使用 String 表达 JSON 文本，SQL NULL 仍由类型 Codec 处理，不在客户端重复解析 JSON。
普通绑定使用 PreparedStatement，字符串值不会拼入 SQL。驱动、类型和时区边界见
[JDBC 类型映射](jdbc-type-mappings.md)，异常安全边界见[运行时错误码](runtime-error-codes.md)。
