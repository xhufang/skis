# 专用投影与属性来源

> 本文按 `0.2.10-SNAPSHOT` 维护；文件名保留历史链接。当前公开版本为 `0.2.0`，本分支能力累计到 `0.3.0`。

## 声明固定属性来源

`@SpecialProjection` 用于结果属性来源可提前声明的 record 或普通类。每个构造值使用生成表的完整属性身份：

```java
@SpecialProjection
public record PetLabel(
    @PropertyFrom(PetTable.ID) Long id,
    @PropertyFrom(PetTable.NAME) String label) {}
```

`PetTable` 从实体包下生成的 `.skis` 子包导入，`PetTable.NAME` 是编译期字符串常量，标识实体属性而非物理列名。
APT 验证来源、Java 类型、构造及可空性，并生成持有不可变来源模板的 `PetLabelPro`：

```java
List<PetLabel> labels = executor.select(PetLabelPro.all())
    .from(PetTable.petTable)
    .orderBy(PetTable.petTable.id().asc())
    .fetchList();
```

`all()` 返回不可变单例。来源模板只保存属性元数据及可选别名，实际表 occurrence 在最终查询块绑定。
单例不会保存当前查询、参数、连接或解析状态，多查询和并发调用之间不会互相污染。

## Join 与别名

来源实体在当前查询块出现多次时，通过 `@PropertyFrom(value = PetTable.NAME, alias = "p")` 明确所需别名。
缺失、歧义、重复或不匹配来源在适用的生成/编译阶段明确拒绝；内部同源关系不能仅凭实体 Java 类型猜测。

LEFT/RIGHT/FULL JOIN 的 null-extension 会影响最终结果可空性。可能缺失一侧的构造参数必须允许 NULL，
APT 的属性声明校验不替代最终查询块校验。完整多表例子见
[ProjectPrincipalView](../skis-test-model/src/main/java/io/skis/projection/ProjectPrincipalView.java)和[Join 合同](joins.md)。

## 生成与装配

需要在调用点自由绑定表达式时，使用[可复用投影](0.0.8-projection-slice.md)的 `@ReusableProjection` 与
`XxxPro.of(...)`。两种注解不混用；两者都不生成 DTO，也不引入投影 Provider、类定位注册表或投影发现索引。

显式配置处理器列表时，当前列表为：

```xml
<annotationProcessors>
  <annotationProcessor>io.skis.processor.SkisEntityProcessor</annotationProcessor>
  <annotationProcessor>io.skis.processor.SkisEntityIndexProcessor</annotationProcessor>
  <annotationProcessor>io.skis.processor.SkisProjectionProcessor</annotationProcessor>
</annotationProcessors>
```

生成器、运行时和当前消费者配套使用，生成 ABI 为 9。完整 POM 与外部装配验证见
[独立消费者](../skis-integration-tests/src/consumer/README.md)，失败定位见[APT 错误码](apt-error-codes.md)。
