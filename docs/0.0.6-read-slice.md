# 执行器、生成模型与实体读取

> 本文按 `0.2.7-SNAPSHOT` 维护；文件名保留历史链接。当前公开版本为 `0.2.0`，本分支能力累计到 `0.3.0`。

## 装配与调用

应用持有一个线程安全的 `SkisExecutor`，显式指定方言：

```java
SkisExecutor executor = Skis.create(dataSource, PostgreSqlDialect.INSTANCE);
PetTable pet = PetTable.petTable;
Optional<Pet> byId = executor.findById(pet, 7L);
SingleRow<Pet> one = executor.selectFrom(pet).where(pet.id().eq(7L)).fetchOne();
List<Pet> all = executor.selectFrom(pet).orderBy(pet.id().asc()).fetchList();
```

`findById` 使用单主键 Fast Path 并保留 Optional 返回合同。通用查询使用 `SelectQuery<R>`，结果类型与 FROM
根类型独立；来源、别名、Join 及子查询 occurrence 仍由编译阶段验证。

SELECT 的 fetchOne/fetchFirst 返回 `SingleRow<R>`：无行、SQL NULL 行、非空值行保持不同状态。
`hasRow()` 表示数据库行存在，`isNull()` 表示存在且值为 NULL，`toOptional()` 只提供非空值视图。
fetchOne 多行失败；fetchFirst 通过 SQL limit 1 读取首行。fetchList 保留合法 null 元素及其位置。

## APT 与模型装配

声明 `@SkisEntity` 后生成 `PetMeta`、`PetTable`、`PetRowDecoder`、`PetBinder` 和 `PetRuntimeModel`。
表单例由实体简单类名首字符小写后追加 Table，例如 `PetTable.petTable`；`PetTable.ID` 等字符串常量是专用
投影的完整属性身份，不是表单例。物理表名、schema 与 SQL 别名不改变 Java 单例字段名称。

执行器装配读取确定的 `META-INF/skis/entities.idx`，默认热路径不进行反射映射、全类路径扫描或运行时注解解析。
容器可通过 `Skis.Builder.runtimeModels(...)` 提供已构造的模型集合。当前生成 ABI 为 7；处理器与运行时须
配套使用，装配会验证 ABI。生成代码和应用扩展不引用 internal 包。

完整无父 POM 的 BOM、APT、runtime、方言和显式驱动配置见[独立消费者](../skis-integration-tests/src/consumer/README.md)。

## 查询结构与缓存

`Sql` 构造无执行器依赖的可复用描述，`executor.query(description).bind(parameter, value)` 绑定当前调用值。
绑定捕获值快照并返回不可变查询，跨调用不会共享可变参数缓冲。

查询依次使用查询对象局部 L0、执行器 catalog 所有的有界共享 L1，以及实际编译 L2。结构键包含结果形状、来源依赖
和稳定方言身份，普通值、监听事件和连接不进入共享计划。别名按结构处理；无法证明稳定身份的扩展明确旁路共享缓存。

`queryPlanCacheStatistics()` 返回真实不可变统计；`clearQueryPlanCache()` 清理共享计划且不重置累计活动计数。
卸载结果类型或插件 ClassLoader 前，须先停止相关执行，再清理共享计划。查询局部计划随查询对象生命周期保留。

JDBC 资源沿用[连接与编译基础](0.0.5-foundation.md)的所有权。分页、流读取与监听分别见
[分页](pagination.md)、[游标与流](cursor-and-stream.md)、[执行监听](execution-listeners.md)。
